# Q2C 使用流程

本文件描述当前实现。安装、授权和首次配置见 [README](../README.md)。

1. 用户触发全局快捷键后，冻结本轮配置，只向来源前台应用发送一次仅含 Command 的 ⌘C。
2. 只观察 changeCount：立即检查，再每 50ms 检查，最多等待 400ms。来源应用切换、版本不更新或复查变化则停止，不读载荷，不回退旧剪贴板，不自动重试。
3. 有效标星目标优先，其余按设置顺序。复制完成时已松键则直接使用第一条有效目标；仍按住则显示选择弹窗。按触发键切换、Shift 反向、松开修饰键确认，也支持鼠标选择。
4. Esc、弹窗 ×、空白/外部点击、失焦、版本变化或等待超时取消；关闭时清理监听。选择浮层的外部点击过滤与设置弹窗的外部点击关闭各自管理。
5. 打开配置的线程深链接，等待 0.2 秒后检查 Codex 前台应用/PID，等待修饰键释放；随后核对剪贴板版本和前台应用，发出一次 ⌘V。
6. 用户在 Codex 中查看并手动发送。操作期间阻止重复触发，不自动发送或重试。

## 设置面板

宽度 600 点，顶部行 40 点、配置行 45 点；分割线贯通左右，高度按内容适配，超过屏幕可用高度时滚动。每行依次为备注、链接、星号和 ×；输入框靠左，按钮靠右，与顶部加号/退出上下对齐。

顶部四按钮及每行星号/× 均无底色、无外框。EN/CN 切换中英文并在本机保存。悬停输入框显示“字段名:”加换行和完整内容。头尾输入框已移除，旧字段不参与转交；不提供拖动排序。

最多 8 组配置，任一链接空白或达到上限时禁用新增。修改约 400ms 后自动保存；删除需确认，删除最后一组后保留空配置及快捷键。备注不参与转交，空备注显示配置在设置中的编号。

## 目标选择弹窗

宽度 300 点，行高 40 点、间距 12 点，按实际条数计算高度；列表超过屏幕上限可滚动。仅顶部文字左侧显示一次 Q2C 图标，星号在配置名右侧。关闭 × 使用 18 点图标和 30×30 点击区域，悬停高亮。
