# Q2C 使用流程

当前已移除头尾输入框及运行时输入，仅保留备注。当前实现以本文件开头流程为准；下方带日期的 AX 识别、聚焦和身份检查记录为历史过程，现已由直接粘贴模式替代。

1. 在来源应用选中内容，按全局快捷键（默认 ⌥⌘C）。Q2C 立即记录来源前台应用和剪贴板版本，向来源应用发出一次仅带 Command 的 ⌘C；不等待物理修饰键释放。
2. 仅观察 changeCount，发出复制事件后立即检查新版本，之后每 50ms 检查一次，最多等待 400ms，更新后立即继续。不读取内容、类型或文件路径；复制失败时不显示选择浮层、不转交。不再等待长短按阈值。
3. 快捷键不区分长短按：先复制一次；复制完成时若已松开修饰键，直接使用第一组有效目标。仍按住时显示浮层，标星项置顶并默认高亮，其余按设置顺序排列；标题提示显示配置快捷键中的按键，按该键切换，鼠标点击确定，松开修饰键确定。Esc、点击空白/外部取消。设置列表不重排，配置X按设置位置编号。无效链接不参与选择，最多等待 60 秒。
4. 打开目标 Codex 深链接，等待 0.2 秒后确认前台应用为 Codex，记录其 PID；不扫描 AX、定位/聚焦输入框或验证任务身份，依赖 Codex 自动聚焦输入框。若当时 Codex 不在前台则停止。
5. 发出一次原样 ⌘V，不输入头尾文字。旧配置里的头尾字段被忽略，不发送 Return 键或点击发送按钮。
6. 提示“已请求粘贴到 Codex，请查看输入框并手动发送”。按用户决定，不检查已有草稿、附件、任务运行状态或粘贴后的正文。原生粘贴/文字输入会遵循目标应用的光标和选区规则。

取文判断是“本次 ⌘C 后观察到剪贴板新版本”，不能证明存在鼠标选区，也不能证明更新一定来自这次复制。来源应用可能复制整条消息或整个项目；目标应用决定哪些格式能接收以及如何表现，Q2C 不解析载荷。观察时间是 Q2C 检测到更新的时间，不是系统提供的剪贴板修改时间。

复制阶段发出一次 ⌘C 后立即检查 changeCount，之后每 50ms 检查一次，最多等待 400ms；更新就继续，超时提示停止。复制、目标选择和粘贴期间阻止重复触发；来源应用切换、复制阶段版本连续变化、导航或输入期间版本再次变化时停止。不自动重试，不保存载荷文件、历史或正文日志。

头尾仍是配置文字：默认均为空，合计最多 64 KiB，拒绝 NUL。剪贴板载荷不受原先的文本长度、空白、格式限制。头尾事件与 ⌘V 按顺序发出；图片/文件导入可能异步，附件与文字的最终排列由 Codex 决定，不做结果核对。部分操作失败时已输入的头尾或已触发的粘贴会保留。

保留上一轮批量 AX 属性读取、粘贴前直接复查窗口与焦点、就绪后尽早继续和毫秒耗时日志。进一步减少了复制内容读取、字符串组合、二次剪贴板写入和载荷缓冲；实际总耗时仍需现场日志确认。

设置文本框继续支持 ⌘A/C/X/V，⌘W 关闭面板，⌘Q 退出。当前只完成编译与合成环境测试；淘宝、Warp 复制、Codex Unicode 头尾输入和各类格式粘贴均待现场确认。“已请求粘贴”不代表内容已确认出现或消息已发送。

## 2026-11-06 聚焦等待与失败诊断

AX 聚焦请求成功后，最多等待 0.5 秒观察指定输入框成为实际焦点，每 20 毫秒复查；等待期间仍检查剪贴板版本、前台窗口及相反任务身份。仅请求一次聚焦，不点击或模拟 Tab，不重试粘贴。输入阶段继续严格复查焦点。聚焦失败、窗口/焦点变化、修饰键未释放分别提示；`paste.focusFailed` 记录原因或 AX 错误码，不记录正文。

设置面板：每组配置右上方常驻删除图标，点击后弹窗确认，取消不修改配置。删除最后一组后保留一组空白配置及现有快捷键供重新填写。开头与结尾输入框并排显示，左侧为开头、右侧为结尾；修改仍自动保存。

深度链接占位提示标注“（必填）”；任一配置的链接为空或仅含空白时，“新建配置”按钮置灰，填写后恢复可用。

配置上限为 8 组；达到上限或任一配置链接为空时，“新建配置”置灰。删除配置后，满足条件即可继续新增；已有超出上限的本机配置不自动删除。

设置面板高度随配置内容增减，宽度保持固定；高度达到当前屏幕可用高度（预留边距）后，配置列表滚动显示。



## 2026-11-06 长短按与先复制

当前流程以上方步骤为准；复制期间保持来源应用前台，浮层期间持续检查剪贴板版本，粘贴前保留焦点和任务身份检查。

输入框支持系统悬停提示：链接、开头和结尾显示当前完整配置内容；空值显示对应填写提示。

点击已标星的五角星可取消标星；点击未标星的配置则将其设为唯一标星。无标星状态自动保存，快捷键按无标星规则选择目标。

配置第二行按三等分排列：备注（可选）、开头、结尾。备注仅作为本机配置名称，自动保存，不参与转交。空备注（含纯空白）显示按设置列表当前位置编号的“配置X”，不写入默认名称。快捷键选择浮层仅显示备注/默认名称，保留星号和高亮，长名称省略并支持悬停显示完整内容；不展示链接或头尾。旧配置缺少备注字段时兼容为空。

## 统一松键确认（2026-11-06）

快捷键不区分长短按：先复制一次；复制完成时若已松开修饰键，直接使用第一组有效目标。仍按住时显示浮层，标星项置顶并默认高亮，其余按设置顺序排列；标题显示当前快捷键的按键，按该键切换，鼠标点击确定，松开修饰键确定。Esc、点击空白/外部取消。设置列表不重排，配置X按设置位置编号。

无 AX 任务 ID 时，导航缓冲从 1 秒调整为 0.5 秒；任务身份明确匹配可立即继续，相反 ID 仍拒绝。聚焦等待上限保持 0.5 秒。跨任务导航的实际时序需现场验证。

输入框完整内容提示改为面板底部自定义浮层：悬停非空链接/备注/开头/结尾立即显示，自动换行，不拦截鼠标；移出、删除配置或关闭面板即隐藏，编辑时同步更新。

2026-11-06 悬停提示调整：取消输入框系统 help 与底部浮层，统一为鼠标右下方的单一提示窗，延迟 200 毫秒，换行显示完整配置文字；不激活窗口、不拦截鼠标，移出/关闭即清理。仅本应用生效，不改系统 tooltip 设置。Release 构建、签名与 diff 检查通过，实际显示效果待确认。

选择浮层右上角 × 可取消转交。浮层显示期间尝试使用 session CGEvent tap 主动过滤外部取消点击，只吞掉首次外部点击的按下、拖动及对应松开；内部按钮仍正常处理。关闭后不再接收新的拦截点击，仅对已吞掉的按下等待配对松开（最多 2 秒）后释放拦截。Esc/×/取消后松键不触发转交。创建失败时记录诊断；由于已移除第二行提示，外部点击保护不可用时，点击仍可能传递给下层应用。不会自动修改权限或系统设置；实际阻止 macOS 隐藏行为的效果仍需现场验证。

“新建配置”按钮位于配置列表下方右侧，仅显示加号，悬停显示说明。顶部说明为“选中内容按快捷键转交到指定的 Codex 对话线程”。

输入框悬停提示按字段添加前缀：深度链接、配置备注、内容开头、内容结尾。前缀仅用于提示，不写入配置或转交内容。

## 设置面板语言与宽度

默认中文，标题栏 EN 按钮切换为简写英文，按钮随即显示 CN，可点击切回中文；语言选择在本机记忆。切换范围为设置面板、字段悬停、删除确认和快捷键录制提示，不翻译用户配置内容。面板固定宽度增至 660 点，给完整深链接留出更多空间；高度仍自适应。

输入框悬停提示将字段名与内容分行显示：第一行“字段名:”，第二行开始显示完整内容，长内容继续自动换行。

快捷键触发的独立目标选择浮层也跟随 EN/CN 设置：操作提示、取消按钮和默认配置编号同步切换，用户备注保持原文。

## 2026-11-06 快捷键选择器提示与限制

选择器保持现有无标题栏浮动面板样式，移除标题下方的第二行说明。标题按配置动态显示实际触发键和完整快捷键；浮层内再次按触发键切换目标，松开修饰键确认，鼠标选择和 Esc/右上角 × 取消保持可用。若外部点击保护启动失败，外部点击仍可能传递给下层应用，此状态只写诊断日志。

快捷键必须由至少一个 ⌘/⌥/⌃/⇧ 修饰键和一个非修饰键组成；单独功能键不再接受。Esc 始终保留作取消键。⌘D 等普通组合可以录入；常见 macOS 系统快捷键（如 ⌘Tab、⌘Space、⌘H/M、截图、桌面切换和锁屏组合）保留。已保存的旧快捷键若违反新规则，需在设置中重新录制。

Q2C 图标统一为自行绘制的黑白右上箭头：应用使用黑底白箭头，菜单栏及选择浮层使用模板箭头适配系统主题。几何源为 app/Q2CApp/Q2CIcon.swift；构建脚本将 app/Resources/Q2C.icns 放入应用资源并由 Info.plist 声明。图标重建：`swiftc app/Q2CApp/Q2CIcon.swift scripts/generate-icons.swift -o /tmp/q2c-generate-icons`，运行生成器指定 .iconset 目录，再用 iconutil 转为 icns。没有引入第三方图标或字体素材。

排查转交失败时，重启新版后复现，查看本机 diagnostic.jsonl 中同一 trace 的 input.rejected、paste.readinessScan、paste.readinessTimeout、paste.focusFailed 和 paste.failureDetail。新版只增加结构与原因日志，等待时间和转交流程保持不变。

## 2026-11-06 输入框识别分层

导航后先验证当前焦点编辑器的结构和所属窗口，再重新验证结构缓存，无法确认时回退当前窗口完整扫描。完整扫描仍要求唯一可用输入框。粘贴前间隔 40 毫秒确认窗口、输入框和焦点稳定；结构变化时停止，不自动重试。任务身份检查独立保留，无身份导航缓冲仍为 0.5 秒。此改动不能保证没有 AX 任务 ID 时一定已切到目标任务。

复制无更新提示缩短为“未选中任何内容 请选中后按快捷键”（左侧为与菜单栏相同的 Q2C 图标），英文模式使用简短英文；显示约 1 秒。该提示仍基于剪贴板未更新，不代表直接检查或读取了选区。来源应用超过等待上限才更新时也会停止，即使实际有选区；不使用旧剪贴板。

短提示窗口按文字测量结果和菜单栏图标自适应，左右留白 20 点、上下 12 点；长文案限制宽度后换行，不再固定为 400×84。

窗口已打开但未粘贴时，新日志版本 diagnostics-v11-ax-structure 会记录焦点/缓存拒绝原因及最多 32 节点的树结构摘要，便于区分输入框未暴露与父链无法确认。重启新版后复现即可，不需要另发测试消息。

## 当前直接粘贴模式（2026-11-06）

导航成功后等待 200ms，仅检查 Codex 前台应用/PID；仍保留 50ms/400ms 来源复制检测、剪贴板版本检查、松键等待、防重复、独立头尾顺序与手动发送。不会核对窗口、焦点或任务身份，输入框是否就绪依赖 Codex。每个输入步骤及 Unicode 分块前检查版本和前台 PID。日志用 paste.actionRequested 表示动作已发出，不能据此确认附件接收或文字实际填入。

配置的头尾继续独立输入；Unicode 分块间留 20ms，头部/粘贴/尾部步骤间留 50ms，空头尾不生成默认文字。文件附件的实际导入顺序仍由 Codex 决定。

## 2026-11-06 移除头尾

设置面板只保留链接行和备注框，目标选择不显示旧头部，删除确认改为链接与备注。旧头尾字段兼容保留但忽略；不读取/清除用户本机配置。转交只发一次原样粘贴，删除 Unicode 输入及其处理间隔。0.2 秒导航等待、50ms/400ms 来源复制检测和手动发送保留。下方/上方旧头尾输入说明均为历史记录。

2026-11-06 布局更新：备注框宽 120 点，移到链接左侧，同一行排列为“备注 → 链接 → 标星 → 删除”；面板宽度由 500 增至 660 点，高度继续自适应。构建方式不变。

顶部说明文字使用 13 点中等字重及主文字颜色，提高可读性；中英文同步。

配置列表移除每行圆角背景及描边，改用相邻配置之间的分割线，首行前和末行后不加分割线。保留单行备注、链接、标星与删除布局；构建方式不变。

设置弹窗按列表固有内容高度测量，配置行间距缩至 6 点，列表顶部留白 8 点、底部 6 点，标题上下 10 点；内容顶部对齐，超过屏幕高度上限仍滚动。构建方式不变。

目标选择浮层仅在顶部操作提示左侧显示一次 Q2C 图标，配置行不重复显示应用图标，保留默认星标。行高 40 点、行间距 8 点，列表高度严格按行数计算并保留屏幕高度上限；浮层底部留白 10 点。构建方式不变。

新建配置加号移到标题栏右侧、退出按钮左边，不再占用列表底部一行。原配置上限及空链接禁用规则保持，选择目标期间禁用新增。构建方式不变。

当前恢复标星方案：设置行保留星号，可标星/取消；浮层有效标星项置顶，其他项按设置顺序，无标星时默认首个有效项。不提供拖动排序。
