# Q2C 使用流程

安装、授权和首次配置见 [README](../README.md)。

## 内容转交

1. 在来源应用中选中内容，按下配置的快捷键。Q2C 固定本轮配置，向来源前台应用发送一次 ⌘C，只观察剪贴板版本变化，不读取、保存或改写内容。
2. 复制未产生新版本或来源应用切换时停止并提示，不使用旧剪贴板，也不自动重试。
3. 有效标星目标优先，其余按设置顺序排列。复制完成时已松开快捷键，则直接使用第一条有效目标；仍按住时显示选择弹窗。按触发键切换、Shift 反向切换，松开修饰键确认，也可用鼠标选择。
4. Q2C 打开所选配置的 Codex 对话深链接，确认 Codex 为前台应用且剪贴板版本未变后，发出一次原样粘贴。
5. 在 Codex 中查看内容并手动发送。转交期间阻止重复触发，不自动发送或重试；发出粘贴操作不代表已确认内容填入。

## 取消转交

按 Esc、点击选择弹窗的 ×、点击空白或外部区域可取消。弹窗失焦、剪贴板版本变化或等待超时也会取消。

## 目标配置

最多支持 8 组配置，每组包含备注和对话深链接。备注仅用于区分目标，不参与转交；未填写备注时显示配置编号。

最多标星一组目标，再次点击星号可取消。任一链接空白或配置达到上限时，不能继续新增。配置修改自动保存在本机，删除前需确认；删除最后一组后保留空配置和快捷键。

中英文界面切换、自定义快捷键及其他操作见 [README](../README.md#快速使用)。
