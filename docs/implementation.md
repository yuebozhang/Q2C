# Q2C 0.2.0 实现说明

当前产品行为见 [使用流程](usage-flow.md)。头尾输入框及运行时文字输入已移除，旧字段仅兼容保留并忽略；头尾相关章节为历史过程。当前已切换直接粘贴：打开链接后等待 200ms，仅检查前台应用/PID 和剪贴板版本，不运行下方历史 AX 识别/聚焦/身份检查。

## 原样复制与目标选择

`SystemSelection` 保留原文件/类型名，当前实现只发出来源应用 Command+C 并观察版本；`SourceCopyEnvironment` 仅暴露权限、前台 PID、修饰键状态、changeCount 和单调时钟，不提供内容或类型访问方法。`CopiedContent` 只保存版本、发送时间与观察时间。

`AssistantModel` 在异步复制前冻结配置，复制后保存版本。快捷键单/多配置均直接使用唯一标星目标（默认第一组）。取消选择不恢复旧剪贴板；来源复制结果保留。选择期间版本变更由粘贴前检查拒绝，不重新取文或改写载荷。

## 独立头尾与粘贴

`ClipboardPasting` 不再提供 copy(message) 接口。`CodexClipboardPaster` 仅检查剪贴板版本、导航、定位输入框、复查焦点和身份，然后执行 PasteSequence：可选开头 Unicode 事件、一次 Command+V、可选结尾 Unicode 事件。头尾按 Unicode scalar 分为最多 20 UTF-16 单元的事件，不拆开代理对，不发 Return 键、不占用剪贴板。仅头尾配置仍由 MessageWrapper.validateAffixes 验证；载荷不使用 MessageWrapper 或 CaptureBuffer，不限制类型、文本长度或空白。

每步验证剪贴板版本和焦点；失败保留已执行的部分且不重试。保持用户选择：不检查草稿、附件和运行状态，不核对正文，不自动发送。目标应用决定是否接收载荷、Unicode 头尾及其最终排列；文件/图片导入可能异步。

## 性能

保留上一轮 PasteReadiness、AX 批量属性读取、确认身份时提前就绪和直接边界复查。移除载荷读取、字符串处理、第二次剪贴板写入和正文缓冲；无头尾时只有一次原样粘贴事件。保留 elapsedMs 和 scans，新增 input.copyReady 的 copyUpdateMs（观察时刻减发送时刻）；这是观测时间，不是系统剪贴板修改时间。实际总耗时仍待现场测速。

## 设置、存储与菜单

保留 schemaVersion 2 多组配置、旧配置只读迁移、默认空头尾和单个全局快捷键；新配置默认 Option+Command+C。各组快捷键字段为兼容存储保留，当前只注册首组字段；目标由配置数量及用户选择决定。

设置输入停止约 400 毫秒后保存；本机文件位于 ~/Library/Application Support/Q2C/config.local.json，目录 0700、文件 0600，不进入 Git。配置文本框的原生编辑菜单支持 Command+A/C/X/V；Command+W 关闭面板，Command+Q 退出应用。这六个组合保留给系统操作。

## 诊断与验证

日志位于 ~/Library/Logs/Q2C，保留 JSONL 轮换和权限规则，不记录正文或剪贴板内容。当前运行标识 `diagnostics-v11-shortcut-picker`。当前测试注入合成版本与输入序列和复制/粘贴适配器，不读取真实选区或剪贴板、不注册全局快捷键、不打开真实任务。真实 Codex 窗口、AX 聚焦与键盘粘贴仍待现场确认。

## 2026-11-06 聚焦等待与失败诊断

AX 聚焦请求成功后，最多等待 0.5 秒观察指定输入框成为实际焦点，每 20 毫秒复查；等待期间仍检查剪贴板版本、前台窗口及相反任务身份。仅请求一次聚焦，不点击或模拟 Tab，不重试粘贴。输入阶段继续严格复查焦点。聚焦失败、窗口/焦点变化、修饰键未释放分别提示；`paste.focusFailed` 记录原因或 AX 错误码，不记录正文。

设置面板：每组配置右上方常驻删除图标，点击后弹窗确认，取消不修改配置。删除最后一组后保留一组空白配置及现有快捷键供重新填写。开头与结尾输入框并排显示，左侧为开头、右侧为结尾；修改仍自动保存。

深度链接占位提示标注“（必填）”；任一配置的链接为空或仅含空白时，“新建配置”按钮置灰，填写后恢复可用。

## 隐私边界

当前快捷键路径只读取 NSPasteboard.changeCount，不读取载荷或类型、不保存载荷；来源应用执行复制，Codex 执行原生粘贴。该路径不发起网络请求，不上传配置或日志，也无遥测与云端同步。目标链接、快捷键及用户配置的头尾文字存于本机配置；诊断日志只记录运行元数据，不记录转交正文。系统剪贴板仍可能保留来源复制内容，用户在 Codex 手动发送后的处理由 Codex 决定。旧提交实现未接入当前快捷键路径。

配置上限为 8 组；达到上限或任一配置链接为空时，“新建配置”置灰。删除配置后，满足条件即可继续新增；已有超出上限的本机配置不自动删除。

设置面板高度随配置内容增减，宽度保持固定；高度达到当前屏幕可用高度（预留边距）后，配置列表滚动显示。

ForwardProfile 新增 isFavorite，兼容旧配置缺失字段；加载时保证最多一组标星，保留无标星状态。点击星号切换，删除标星组后保持无标星；触发时冻结的配置决定路由。当前快捷键不区分按住时长，统一使用标星目标；无标星且多配置时显示目标选择器，另保留显式 useFavorite: false 的测试入口。


## 2026-11-06 长短按实现（覆盖此前统一标星路由）

GlobalShortcut 首次触发创建 ShortcutInteraction；SystemSelection 立即复制一次，resolve 根据松键状态直接确定或显示浮层。结束时清理监听、采样任务与浮层。

输入框支持系统悬停提示：链接、开头和结尾显示当前完整配置内容；空值显示对应填写提示。

点击已标星的五角星可取消标星；点击未标星的配置则将其设为唯一标星。无标星状态自动保存，快捷键按无标星规则选择目标。

配置第二行按三等分排列：备注（可选）、开头、结尾。备注仅作为本机配置名称，自动保存，不参与转交。空备注（含纯空白）显示按设置列表当前位置编号的“配置X”，不写入默认名称。快捷键选择浮层仅显示备注/默认名称，保留星号和高亮，长名称省略并支持悬停显示完整内容；不展示链接或头尾。旧配置缺少备注字段时兼容为空。

## 统一松键确认（2026-11-06）

快捷键不区分长短按：先复制一次；复制完成时若已松开修饰键，直接使用第一组有效目标。仍按住时显示浮层，按设置顺序排列，默认高亮第一条有效配置；标题显示当前快捷键的按键，按该键切换，鼠标点击确定，松开修饰键确定。Esc、点击空白/外部取消。设置列表不重排，配置X按设置位置编号。

无 AX 任务 ID 时，导航缓冲从 1 秒调整为 0.5 秒；任务身份明确匹配可立即继续，相反 ID 仍拒绝。聚焦等待上限保持 0.5 秒。跨任务导航的实际时序需现场验证。

输入框完整内容提示改为面板底部自定义浮层：悬停非空链接/备注/开头/结尾立即显示，自动换行，不拦截鼠标；移出、删除配置或关闭面板即隐藏，编辑时同步更新。

2026-11-06 悬停提示调整：取消输入框系统 help 与底部浮层，统一为鼠标右下方的单一提示窗，延迟 200 毫秒，换行显示完整配置文字；不激活窗口、不拦截鼠标，移出/关闭即清理。仅本应用生效，不改系统 tooltip 设置。Release 构建、签名与 diff 检查通过，实际显示效果待确认。

选择浮层右上角 × 可取消转交。浮层显示期间尝试使用 session CGEvent tap 主动过滤外部取消点击，只吞掉首次外部点击的按下、拖动及对应松开；内部按钮仍正常处理。关闭后不再接收新的拦截点击，仅对已吞掉的按下等待配对松开（最多 2 秒）后释放拦截。Esc/×/取消后松键不触发转交。创建失败时记录诊断；由于已移除第二行提示，外部点击保护不可用时，点击仍可能传递给下层应用。不会自动修改权限或系统设置；实际阻止 macOS 隐藏行为的效果仍需现场验证。

输入框悬停提示按字段添加前缀：深度链接、配置备注、内容开头、内容结尾。前缀仅用于提示，不写入配置或转交内容。

## 设置面板语言

AssistantView 通过 AppStorage 的 Q2C.interfaceEnglish 本机偏好保存语言，默认 false（中文）；标题 EN/CN 按钮即时切换设置文案，ShortcutRecorder 同步更新。配置正文不参与翻译。面板宽度为 660 点。构建仍使用 `zsh scripts/build-app.sh`。

Q2C 图标统一为自行绘制的黑白右上箭头：应用使用黑底白箭头，菜单栏及选择浮层使用模板箭头适配系统主题。几何源为 app/Q2CApp/Q2CIcon.swift；构建脚本将 app/Resources/Q2C.icns 放入应用资源并由 Info.plist 声明。图标重建：`swiftc app/Q2CApp/Q2CIcon.swift scripts/generate-icons.swift -o /tmp/q2c-generate-icons`，运行生成器指定 .iconset 目录，再用 iconutil 转为 icns。没有引入第三方图标或字体素材。

## 2026-11-06 输入识别诊断日志

新增 paste.readinessScan：记录前台/窗口是否可用、AX 读取错误码、扫描节点数、输入框数、禁用状态和任务身份分类（不记录 ID、URL 或 AX 正文）。状态变化时记录，相同状态每秒最多一条；paste.readinessTimeout 记录最后扫描状态、次数和耗时。paste.failureDetail 为粘贴失败补充具体枚举原因及耗时，保留原 paste.failed 事件；input.rejected 补充来源复制具体拒绝原因和耗时。既有 paste.focusFailed 继续细分焦点问题。时间参数不变：无身份导航缓冲 0.5 秒，聚焦等待 0.5 秒，识别总超时 7 秒。

构建使用 `zsh scripts/build-app.sh`；退出旧版再打开产物，通过 app.started 的 diagnostics-v14-clipboard-only 确认运行版本。需要真实界面复现后才能判断原故障原因；无需读取剪贴板载荷或试发消息。

## 2026-11-06 分层输入识别

先检查当前焦点，要求启用的 AXTextArea、ProseMirror DOM class，并沿最多 64 层父链验证同进程、未隐藏、经过一个网页区域且连接当前焦点窗口；只读取结构标记，不读正文或占位文字。失败时复查缓存控件的同样条件，窗口/PID 不匹配或失效即丢弃；仍不确认则完整扫描当前窗口，保持唯一输入框条件。ProseMirror 标记来自本机只读结构观察，界面变化时回退扫描；该标记和稳定焦点不证明任务身份。

完整扫描的批量属性读取失败时，改用单独的结构属性查询。仅已知叶节点缺少可选 children（attributeUnsupported/noValue）可继续；容器或未知角色 children 不可读、真实 AX 错误仍拒绝本轮确认，不把所有错误当作叶节点。

聚焦并松键后相隔 40 毫秒两次检查剪贴板版本、同一前台窗口、同一输入框及焦点、启用状态和任务身份；不稳定即停止，不重新聚焦或重试粘贴。每个输入步骤继续做同样边界检查。缓存仅是结构提示，身份仍逐次检查；AX 无 ID 时保留 0.5 秒导航缓冲，聚焦上限 0.5 秒、扫描总超时 7 秒不变。readinessScan 的 path 区分 focused/cached/fullScan，新增 inputStable 阶段。未启用或更改目标应用的辅助功能模式。

## 2026-11-06 加快复制无更新提示

来源复制发出事件后立即检查新版本，之后每 50ms 检查一次，采用从发送前计时的 400ms 单调时钟期限；更新就立即继续，不额外等待稳定窗口。copyUnavailable 使用简短中英文提示，显示时长仍为 1 秒，导航和聚焦时间参数不变。因为系统复制事件异步处理，超时未更新不能证明没有选区，较慢来源应用仍可能超时。按用户要求保留原超时文案：“未选中任何内容 请选中后按快捷键” / “No selection. Select content and press the shortcut.”。

短提示图标使用 Q2CIcon.menuImage()，与菜单栏共用绘制，不再用警告字符；图标与提示文字水平排列、垂直居中。构建方式不变。
## 2026-11-06 选择器提示与快捷键约束

选择器保留现有无标题栏置顶 NSPanel 样式，移除标题下方的辅助提示行。主提示按录制快捷键动态显示触发键和完整组合键。快捷键需至少包含一个 ⌘/⌥/⌃/⇧ 修饰键及一个普通按键；选择器只用触发键切换，松开修饰键确认，Esc 保留为取消键。单独 F 键不再支持。

常用 macOS 全局快捷键及系统操作组合会在录制和注册前拒绝；⌘D 等普通按键组合可以设置。外部点击保护不可用时不再在选择器内显示第二行警告，原因仍写入诊断日志；外部点击可能传递给下层应用。已有不符合规则的快捷键需要用户重新录制。此轮未运行测试或构建，未启动应用或注册全局快捷键。

提示窗口基于实际字体测量，宽度为图标、间距、文字及留白之和，高度随换行增长；文字宽度上限 440 点并受屏幕宽度约束。
