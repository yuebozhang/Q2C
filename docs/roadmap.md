# Q2C 实施路线

当前实现见 [使用流程](usage-flow.md)：来源应用 ⌘C → 观察剪贴板新版本 → 单配置直达/多配置选择 → 深链接导航 → 独立输入头部 → 原样 ⌘V → 独立输入尾部 → 用户发送。

剪贴板载荷不解析、不筛选、不改写，保留来源应用提供的所有格式。复制没有更新则提示。保留上一轮导航/AX 查找优化和阶段耗时日志；不检查草稿/附件/运行状态或粘贴结果，不自动发送。

待现场验证：淘宝、Warp 等来源复制行为，Codex 接收各类格式、Unicode 头尾、异步附件与文字顺序。后续按实际耗时日志继续定位瓶颈；不以减少代码等待代替实测结论。

旧自动发送、App Server 与 proxy 路线保留为历史实现，不由当前快捷键调用。
